# Archive des anciennes migrations Lovable

Ces fichiers SQL ont été générés par Lovable avec des horodatages qui ne correspondent pas
à l'historique réellement enregistré dans la base de production (projet zkhrtvgnzcufplzhophz).
Leur contenu est soit déjà appliqué sous un autre horodatage (38 fichiers), soit un ancien
brouillon dépassé (4 fichiers de septembre 2025).

**Ne jamais les exécuter.** L'historique de référence est dans `supabase/migrations/`,
récupéré depuis la base avec `supabase migration fetch --remote` le 20/11/2026.
